## 🇬🇧 English

The guides for installing, using and operating Nestwerk are available in English (`en/`) and German. The internal design documents are written in German; `en/ARCHITECTURE.md` is an English overview.

### English documents (`en/`)

- [INSTALLATION.md](en/INSTALLATION.md): step-by-step installation on a Debian VM, with reverse proxy, DNS, devices and troubleshooting
- [USER-GUIDE.md](en/USER-GUIDE.md): for parents and kids: tasks, points, ranks, badges, avatars, learning and more
- [RUNBOOK.md](en/RUNBOOK.md): operations: updates, rollback, backup restore, secrets, troubleshooting
- [EXTENDING-MODULES.md](en/EXTENDING-MODULES.md): how to add a new module, using `lernen` (learning) as the example
- [i18n.md](en/i18n.md): how the German/English translations work
- [ARCHITECTURE.md](en/ARCHITECTURE.md): short English overview of the architecture (summary of the German document)

### German-only documents

- [SPEC.md](SPEC.md): product specification and decisions
- [ARCHITECTURE.md](ARCHITECTURE.md): full architecture, layers, dependency rules, events, rule engine (English summary: [en/ARCHITECTURE.md](en/ARCHITECTURE.md))
- [DATA_MODEL.md](DATA_MODEL.md): data model per app, settings and starting values
- [research/web-push.md](research/web-push.md): web push for iOS, Android and kiosk tablets
